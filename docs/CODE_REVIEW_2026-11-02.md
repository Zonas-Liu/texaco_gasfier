## 保留的模型问题与限制

1. `ENTFED` 的 CO2 进料焓仍按原 Fortran 使用 ENTHP(7, N2)，而不是 CO2。代码已有明确兼容说明，本次不在基础维护中改变该物理行为。非零 RATIO_CO2 的能量预测需要专项对比和模型修订；典型工况 RATIO_CO2=0 不受影响。修复的能量诊断与现有组装使用相同 FEEDH[3]。
2. RSC 松弛源项按每格 FEM 计算，未按网格长度归一化；改变 N_RSC 可能改变反应程度。既有参数按 30 格标定，不能把网格数变化仅当精度变化。
3. 现有 SUMFE 等指标是线性求解后的牛顿修正量绝对值和，并非原始守恒残差。本次保留收敛算法；工业使用仍需独立的元素与能量闭合检查。
4. 蒸汽关联式、定值有效壁温、动力学和气固速度近似未重新校准。`kontr()` 的辅助诊断修复不代表已经证明全模型守恒；历史 KCHECK/焦油辅助路径不在本次典型工况覆盖范围。
5. Flask 锁只覆盖单进程服务。Streamlit、Flask 和 CLI 共用文件，不支持同时运行；未扩展为多用户任务隔离服务。打包 GUI 的并发会话也不受本次 Web 锁保护。
6. 历史 `docs/code_reference`、TODO、ISSUE_REGISTRY 以及 Fortran 对比摘要保留，内容可能仅对应移植阶段；最新运行约定见 README/AGENTS。数值等价与工程准确性分别评估。
