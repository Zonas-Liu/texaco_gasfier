# 辐射废锅目标出口温度与产汽联动

2026-11-02后续更新：正式RSC方程已修复守恒，汽水物性已更新为IF97；最新结果见[修复报告](ELEMENT_BALANCE_FIX.md)。下方初版验收数值仅作历史记录，不代表当前模型输出。

## 使用方式

在 Web 左侧展开“辐射废锅设计”，炉型选择晋华炉 3.0，计算模式选择“目标出口温度”。设置目标温度（℃）、高度搜索初值和上下限，并核对汽包压力（MPaG）、给水温度（℃）、内径及有效壁温。文件/API仍用Pa绝压及K。点击运行后，总览显示实际出口温度、计算有效高度、废锅回收热负荷和产汽量。

原有“固定高度”模式仍可用。输入文件缺少第15行时采用固定高度模式，文件格式兼容；后续守恒/物性修复会改变晋华炉结果。第15行为：

```text
1,780,1,120/ RSC_MODE,T_RSC_OUT_C,H_RSC_MIN,H_RSC_MAX
```

模式 0 为固定高度；模式 1 以 780℃为目标，在 1–120 m 范围搜索。H_RSC 是模式 0 的给定高度、模式 1 的搜索初值；求出的高度记录在结果中，不静默覆写输入初值。温度容差 ±0.5℃，最多计算 18 个候选。

## 计算关系

1. 外层按候选有效高度重建 RSC 几何，N_RSC 不变，单元长度为 H_RSC/N_RSC。
2. 内层求解完整气化炉组分与能量方程，仍使用现有 WGS、甲烷化及壁面辐射模型。高度变化会同时影响换热面积、流动及反应状态，不能仅调整显示温度。
3. 内层收敛后刷新派生量，累加 RSC 各格壁面吸热：Q_RSC = ΣQKW[i]，i > NZRC。
4. 产汽量（kg/s）= Q_RSC（W）/{[h_steam(P_DRUM) − h_fw(T_FW,P_DRUM)]（kJ/kg）×1000}；乘3.6换算为t/h。汽水物性均按IF97、给水取汽包压力的压缩液焓。水冷壁与RSC分段计算后得到总产汽量。
5. 用实际出口温度与目标值之差继续寻找高度。先有界扩展找到异号区间，再做限制在区间中间 70% 内的割线搜索。后续候选沿用上一轮状态作为初值，但重新求解全部方程。

出口温度、有效高度、产汽量不是三个可以任意独立指定的固定量。现有模型的汽包压力和给水温度通过汽水焓差影响产汽量；TW_RSC 是另行给定的有效壁温，不会自动随汽包压力更新。

只接受“内层收敛且温度目标达到”的结果。目标未找到、超过搜索次数或内层不收敛均返回 2，并保留明确的失败说明；失败候选不覆盖 START.DAT。模型异常仍抛出并返回非零。GASTEST 末尾的 RSC_DESIGN_JSON 保存同次设计结果和每轮高度、温度、热负荷、产汽及内层迭代次数。收敛过程标签展示最终候选的内层历史，设计明细展示外层过程。

## 双出口数据

合成气页同时展示第 30 格燃烧室出口和最后一格辐射废锅出口：温度、干基流量、H₂/CO、干湿基组成、各组分标况流量及湿基总流量。两幅组成图使用相同横轴范围。

数据只来自同一份 GASTEST：流量取 KOLERG 已有的两出口对照表；温度和湿基组成取对应格号的分布表。燃烧室干基组成由湿基组分去水后归一化，最终出口优先使用已有干基汇总。历史输出的舍入精度会影响末位；不读取当前输入反推历史出口。缺少燃烧室流量的历史输出显示破折号。TEXACO 仅显示其单一出口，不虚构 RSC。

## 适用边界

这是当前一维模型下的**有效换热高度反算**，不是机械尺寸定型。汽水侧IF97已通过官方校核点；定值有效壁温、辐射模型和逐格松弛反应的适用限制仍然存在。受测工况已另做独立元素闭合；温度达到设定值仍不替代全操作范围、独立能量闭合和实际设备校核。
