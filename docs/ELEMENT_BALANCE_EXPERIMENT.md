**结论：典型工况下，进口至燃烧室出口守恒；辐射废锅段不守恒。问题在 RSC 反应源项与原方程行缩放的拼接，不是显示精度或 SciPy 线性求解器造成。** 本次提交实验脚本、测试和证据；正式 `src` 方程未改动。候选修正仅在隔离副本运行。

## 边界与口径

- 输入取仓库当前 `data/Datain0.dat`：水煤浆14 kg/s、煤质量分数0.6、FOXY=0.98、氧纯度0.996、OX_PART=1、RATIO_CO2=0，燃烧室30格、废锅30格／30 m，KRELAX_WGS=2、KRELAX_METH=0.02。固定进料、固定高度、KTRL=1，不使用历史重启。
- 煤30,240 kg/h，配浆水20,160 kg/h，纯氧25,189.920 kg/h，氧气流中N₂杂质88.516795 kg/h。煤元素分析使用原输入值，不重归一化、不换分析基准；本例ELH2O=0。
- 进口从煤元素分析、配浆水、煤内水和氧化剂/CO₂流独立计算；燃烧室出口取第30格，废锅出口取第60格。两处出口均包含湿气全部8组分、未反应碳 `WE*X` 及灰 `WE*(1-X)`。未从干基百分比或打印后的舍入流量反推。
- 原模型原子量采用 C=12、H=1、O=16、N=14、S=32 kg/kmol。守恒量统一为 kg/h。对气相使用独立元素组成矩阵乘 FEMF，再加固体流。
- 灰是惰性整体账项，不是单一元素；未进一步展开其Si、Al、Ca及矿物氧。表中氧与输入ELO一致，不额外把灰内氧重复计入。
- 冷却水/副产蒸汽是独立的水侧边界，模型中只有跨壁换热，没有向合成气侧注入这些水；合成气本身的H₂O已全部计入。

审计通过标准：每项 `|出口−进口| ≤ max(1e-6 kg/h, 进口量×1e-8)`，与牛顿修正量收敛阈值分开判断。该阈值用于数值实验，不表示模型对实际装置的预测精度。

## 根因与定量闭合

`src/subroutines/gasifier_main.py` 中，CO₂基础平衡在第198行除以1.2，H₂基础平衡在第229行乘以1.02；之后第295–296行才加入没有同步缩放的RSC源项。

设未缩放的基础残差为 `B_CO2`、`B_H2`，WGS速率为 `rw`，甲烷化速率为 `rm`。当前实际求解的是：

```text
B_CO2 / 1.2 + rw = 0       → B_CO2 + 1.2*rw = 0
1.02*B_H2 + rw - 3*rm = 0  → B_H2 + (rw - 3*rm)/1.02 = 0
```

另外CO、CH₄、H₂O行未作同样变更，反应化学计量关系因此被破坏。单独缩放一个完整方程不改变其根，但必须同时缩放该行的全部源项。

按基准收敛状态独立重算，废锅全部格子的反应速率之和为：

```text
Σrw = −0.07745889738341646 kmol/s
Σrm = +0.005738082793962566 kmol/s
```

由代码直接推导出的净元素缺口为：

```text
ΔC = 12 × 0.2 × Σrw × 3600
   = −669.244873393 kg/h
ΔO = 32 × 0.2 × Σrw × 3600
   = −1784.652995714 kg/h
ΔH = 2 × (1/1.02 − 1) × (Σrw − 3Σrm) × 3600
   = +13.365620579 kg/h
```

这与直接比较三截面得到的缺口一致，最大差约5.31e-8 kg/h；使用收紧阈值工况，该差降至约5.1e-11 kg/h。根因不仅有代码推断，也有定量证据。

## 候选修正及影响（仅隔离实验）

实验副本保留原基础方程的缩放，只让新增RSC源项乘以同一系数：

```python
common.DMAT[4, i] += r_wgs / 1.2
common.DMAT[6, i] += (r_wgs - 3.0 * r_meth) * 1.02
```

该方案未改任何反应系数、进料、网格或收敛阈值。三截面全部元素与灰恢复闭合，最终出口相对进口的最大绝对误差小于1e-9 kg/h。温度和热回收也随组分/焓平衡改变：

| 固定30 m废锅 | 原模型 | 一致缩放候选 |
|---|---:|---:|
| 废锅出口温度 | 756.862℃ | 790.902℃ |
| 废锅热负荷 | 14.467 MW | 18.013 MW |
| 废锅产汽 | 24.318 t/h | 30.278 t/h |

因此原废锅出口组成、温度和产汽结果不能仅凭“数值收敛”判为可信。正式采用修正时，还需重新核验目标温度求高度、双目标进料反算及联合设计的完整结果；本次没有把该单个候选试验等同于全工况验证或实际物性/装置验证。
