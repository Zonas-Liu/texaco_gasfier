# 后续工作与依赖顺序

[现行问题登记](ISSUE_REGISTRY.md) · [历史计划原文](archive/TODO_2026-06-15.md)

这是后续研发建议，不是已完成工作，也不是本轮整理中的隐式公式变更。

## 第一阶段：建立能量验收

1. 明确HU和煤元素/水/灰的共同分析基准，追溯QHCRCT原始量纲及生成焓参考态（DOC-01）。
2. 建立独立于KONTR的三截面能量账，分别列外部物流、残碳/灰、壁面热量、经验损失与煤热值校正，避免反应热重复计算。
3. 在此账上修正并验证CO₂进料焓（DOC-02），再处理气侧热容/水表/相态（DOC-03）。

接受条件：常数来源可追溯、能量项单位一致、独立闭合有明确阈值，并记录正算/反算及TEXACO兼容影响。

## 第二阶段：连续模型和网格研究

1. 定义RSC松弛源项的时间/空间尺度（DOC-04），研究固定高度下1/5/10/20/30格敏感性；不同网格沿用每格常数不能直接证明网格无关。
2. 验证高压混合气与颗粒闭合、持料量及EPS（DOC-05），量化与当前近似的差异。
3. 排查XVM=0全炉不收敛（DOC-08），研究原方程残差尺度化验收（DOC-10）。

接受条件：元素与能量闭合、内层收敛、网格趋势和适用域都有证据，不只看曲线平滑。

## 第三阶段：服务及输出可靠性

- 统一失败重启策略（DOC-06），区分数值完成、物理验收与文件写入成功。
- 用任务目录/进程隔离支持并发（DOC-07），补结果归属与版本元数据。
- 增加明确的轴向坐标、残碳、总固体和碳转化率字段（DOC-09），保留旧解析兼容。
- 增加煤分析和状态合法性检查（DOC-11），不替用户自动归一化或换分析基准。

## 持续维护

源码符号索引由AST更新，公式和失败语义人工审读；新增功能同步对应章节、参数协议、AGENTS和真实回归。数值重构、物理修订、UI变化尽量分提交，保留可审查的影响边界。
