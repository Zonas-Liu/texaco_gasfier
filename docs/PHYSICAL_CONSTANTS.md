# 物理常数、摩尔质量与蒸汽物性基准

更新：2026-11-02。适用于晋华炉 `KMODEL=1`；数值结果及守恒验收见 [修复验收报告](ELEMENT_BALANCE_FIX.md)。

## 基准与来源

元素的相对原子质量和物质的相对分子质量是无量纲量。程序质量—物质的量换算使用摩尔质量，单位 **kg/kmol**；下表数值按工程惯例由同一套标准原子量求和。天然元素存在同位素组成差异，增加无来源的小数位不会提高准确度。

- **CIAAW 2024**：[简明标准原子量表](https://ciaaw.org/abridged-atomic-weights.htm)及[标准原子量区间说明](https://ciaaw.org/atomic-weights.htm)。选择简明值，避免各组分使用互不相容的旧原子量表。
- **NIST/CODATA 2022**：[官方常数表](https://physics.nist.gov/cuu/pdf/all.pdf)。SI 定义常数用于导出气体常数和辐射常数；标准重力是约定值，不是装置所在地重力的测量值。
- **IAPWS**：[IF97 官方发布页](https://iapws.org/technical-guidance/release/IF97-Rev)、[R7-97(2012) 官方公式与校核点](https://iapws.org/technical-guidance/release/IF97-Rev.download)。汽包及给水使用开源实现 [jjgomera/iapws](https://github.com/jjgomera/iapws)，本次验证版本为 **1.5.5**。
- **IUPAC**：[calorie 的不同定义](https://goldbook.iupac.org/terms/view/C00784)。热化学卡为精确的4.184 J；不能将原经验热容表中出处不明的4.186直接替换后宣称更准确。

标方定义保持 **0℃、101325 Pa、理想气体**，没有改成1 bar；相同摩尔流量的标方量比原近似增加约0.062364%。核心/API/输入文件仍使用Pa绝压与K，界面仍使用MPaG与℃。

更新贯穿：氧化剂/水/CO₂进料、煤挥发分与残碳、碳反应质量换算、热校正中的质量—摩尔转换、气体及固体焓的质量基准、出口流量、元素诊断、双目标反算。H₂S中的硫使用S原子量，不再借用数值相同的旧O₂摩尔质量。

物性接口的 `MOLG` 与主模型采用相同质量表。附带修复 `FXMUG` 的组分错位：旧9组分表中第2项是丁烷，第9项才是甲烷；晋华炉按实际8组分映射。该接口不替代主流程 `XMASS` 当前的粘度近似。

## 汽包和给水：IF97

`steam_props.py` 已替换原简化拟合。汽包4–10 MPa**绝压**范围保持不变；饱和温度、饱和液/汽焓及潜热均由IF97获得。给水焓使用**汽包压力下的压缩液焓**，不再以定比热乘温度代替。给水必须不低于0℃且低于该压力的饱和温度。

```text
产汽量[kg/s] = Q[W] / ((h_sat_vapor(P) - h_feedwater(T,P))[kJ/kg] × 1000)
```

水侧焓用于回收热量换算。气化反应侧 `ENTHP` 包含标准生成焓，未直接替换为IF97水侧焓，避免混用焓零点。IF97内部的拟合常数（例如R=0.461526 kJ/(kg·K)、Tc=647.096 K、Pc=22.064 MPa）是该关联式的一部分，不能用新的通用常数局部替换。

独立校核采用官方表5、15的6个焓值及表36的10 MPa饱和温度，误差分别小于5×10⁻⁶ kJ/kg、5×10⁻⁷ K；并检查4、6.5、10 MPa的产汽量与热负荷闭合。这是实现校核，不是对真实装置、给水压降或全模型预测误差的保证。

## 兼容性与结果追溯

- `KMODEL=0` 固定使用 `fortran-legacy` 配置，保留原粗略原子量、22.4标方换算及旧物性接口行为，用于原TEXACO逐位对照。它不是推荐的新物性配置。
- `KMODEL=1` 使用 `CIAAW-2024-CODATA-2022`。没有新增输入行；现有工况文件可直接运行。计算结果会改变，旧结果不能作为当前模型校准值继续引用。
- `OUTLET_FLOWS_JSON` 保存当次常数基准、标况温压及摩尔体积。解析历史结果若无元数据，沿用22.4，不能套用当前输入/常数去改写历史流量。
- 本次回归确认TEXACO62次收敛；详见修复验收报告中的完整状态/重启文件比较。

## 保留的模型近似与待验证项

本次核对基础常数及质量换算，未把所有经验参数改为更多小数位。以下项有明确的独立模型验证需求：

1. 反应动力学、WGS/甲烷化平衡近似、辐射发射率、有效壁温、煤热值及粒子性质均是模型/工况参数，不是普适精确常数；本次未重新拟合。
2. 气体/固体历史热容系数与生成焓表仍保留。热容换算4.186已命名为历史系数；其cal制出处不完整，未擅自改成4.184。反应侧热力学数据更新需要成套核验参考态和热校正，不能零散替换。
3. `fh2o_fortran.py` 中647.3 K、221.287 bar等是**旧水表的拟合归一化参数**，与其整套系数绑定，并非新的推荐临界物性；保留该关联式，仅统一晋华炉的水摩尔质量换算。水侧IF97与此分离。
4. `mass_flow.py` 的 `ROG=353.5/T` 是历史空气密度代理，未使用气化炉实际压力和组成；对应粘度与颗粒停留时间仍需单独验证。已更正代码中该系数的量纲说明，没有冒充为准确的高压合成气密度。
5. `KCHECK=1` 历史辅助模式不在本次全炉验收范围。`XVM=0` 路径修正了H/O/N/S传参错位及H₂S耗氢，源项单元测试守恒；但默认其他输入下100次仍未收敛，不能宣称该边界已完成全炉验证。
6. 本次证明的是受测工况的C/H/O/N/S及惰性灰质量闭合；没有将灰拆解为矿物元素，也没有完成独立的全炉能量闭合或实际装置标定。
