# 图表与数据表细节设计

## 设计计划与复核

面向核对出口组成、流量和沿程变化的工艺用户，继承[工艺工作台](UI_REDESIGN_2026-11-02.md)的主体结构。采用frontend-design的先规划、复核、实现、截图检查流程。

配色保留白色数据面`#FFFFFF`、蓝灰背景`#EDF2F7`、深蓝文字`#24334A`、主操作`#204F9C`、燃烧室琥珀`#C16B22`、废锅蓝`#5A8CBB`。中文使用Microsoft YaHei UI，数字使用Bahnschrift和tabular-nums；表格数据13px、列名12px、单位11px。数据右对齐，名称和说明左对齐。

初案仅收紧原有卡片间距。复核后认为两张独立出口图表会继续迫使用户跨区查找同一组分，故改为同一组分轴上的成组条形图与统一出口矩阵。颜色在该图中区分出口，在沿程组分图中区分物种；每幅图独立明确标注图例。

```text
原版：出口1 [温度/条形图/整张表] | 出口2 [温度/条形图/整张表]
改版：组成对比图 [干基/湿基]     | 紧凑出口读数（温度、气量、灰）
      统一组分表：组分 | 出口1 干/湿/流量 | 出口2 干/湿/流量
      流量单位切换、表头单位分行、记录数量与数据下载
```

克制原则：不为每个值增加卡片；不平滑、截断或修改原始计算数据。微量正数不得因显示精度变成零，缺失值不得变成零。折线图提供明确单位的悬停信息、轻网格和恢复视图入口；对数轴使用科学计数语义。表格固定组分列、区分出口列组，并允许键盘和触屏滚动。

## 实现与验收

### 图表

- 出口页把两张独立条形图合为同一组分轴上的成组条形图，颜色对应燃烧室和废锅。干基/湿基按钮仅改变组成图的基准，明细表始终同时保留两种基准。
- 概览的组分数值放在固定右侧读数列，避免短条形和微量组分的标签挤在纵轴旁。微量非零值在图、表中均保留科学计数语义。
- 折线使用2.4px线宽、轻网格、纵轴单位和完整悬停单位；多序列图例移到坐标轴下方。收敛图以`10^n`显示数量级，两幅图的坐标绘图区底部对齐。
- 主要组分图采用CO/H2/CO2/H2O；另一幅图显示CH4/N2/H2S/O2，避免水蒸气压缩其余组分的可见变化。每个物种仍使用自身原始序列。
- 炉内分布和收敛页提供“恢复坐标范围”，通过Plotly.relayout恢复各轴自动范围，不改变物种可见性或计算数据。

### 表格与数值口径

- `renderOutletMatrix`按出口分组列出干基%、湿基%和流量。默认kmol/h，也可选择Nm³/h、Nm³/s；前者读取同次输出的摩尔流量，标方小时流量由同次Nm³/s乘3600，不从当前输入或新的物性常数反推旧结果。
- 每列的单位放在第二行，组分列固定；合计与灰分开。干湿基组成合计只在全部相应物种都有数据时计算；气体总流量读取同次输出的合计字段。缺失值显示破折号。
- `numberCell`通常保留3位小数；非零且绝对值小于显示位数阈值时改用科学计数，正负号保留。`title`记录未格式化的原数值，显示精度不会改写内存中的结果。
- `outletCsv`导出当前所选流量单位下的8种组分、合计与灰，UTF-8 BOM便于Excel读取；数值保留来源JavaScript数值精度，不从表格显示字符串反解析。
- 通用明细表把第30格及最终出口格标为对应出口；使用行标题、可聚焦滚动区、记录数量、悬停原值及清晰的收敛状态文本。

## 2026-11-03 明细表二次细化

本轮只调整组分与流量明细表。初案继续增加底色和分隔线，复核认为这会进一步加重表头，故改为更紧凑的两级表头、固定列宽和数字层级。沿用白/蓝灰/深蓝/热端琥珀/废锅蓝；正文中文字体不变，表格数值14px，整数与小数部分分层，组分公式14px、中文名称11px，单位11px。

```text
组分 [公式 + 名称] | 出口名称                  温度
                  | 干基 %     湿基 %       流量 单位
                  | 整数.小数  整数.小数    强调流量
气体合计          | 组成合计   组成合计     含水流量
固相灰            |                       数值 kg/h
```

全部数值继续右对齐；名称左对齐。水蒸气干基栏明确标为“不计”，缺失值继续显示破折号。出口标识和列组分隔表达实际位置关系，颜色不承担唯一识别作用。保留单位切换、原始精度下载、固定首列和窄屏滚动。

实现中使用`outletMatrixHtml`生成表头/列组/行结构，`matrixNumber`仅对整数和小数部分分别着色；两部分保持内联连续文本，避免复制时产生断行。列宽由colgroup固定，流量列加轻底色和数值强调。出口名称与温度分开对齐，气体合计与带kg/h单位的固相灰分成两层，水蒸气不适用的干基栏与缺失数据严格区分。

本次浏览器验收覆盖当前TEXACO单出口、已有晋华炉真实双出口快照、三种单位、390px/320px布局和首列固定。双出口桌面检查未发现数值越出单元格；手机页面宽度与375px/305px可用宽度一致。新增回归验证数字分层后的完整文本、微量/缺失值、不适用标识、单位语义及来源数据不变。展示层回归、JavaScript语法、文档链接检查均通过，浏览器控制台无错误。四个工况/结果文件与本轮开始时哈希一致。截图及哈希记录位于本地忽略目录`numeric_test/python_output/matrix-refinement/`。
