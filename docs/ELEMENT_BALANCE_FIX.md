# 元素守恒修复与物性更新验收

日期：2026-11-02；基础提交 `0412887a92333825494e00f51fe916eab9011d31` 加本次修复。被测源码哈希、完整精度三截面结果和案例摘要保存在 [element_balance_fixed_results.json](element_balance_fixed_results.json)。原始缺陷证据继续保留在 [历史实验报告](ELEMENT_BALANCE_EXPERIMENT.md)，不覆盖原始数据。

## 正式修复

RSC新增CO₂/H₂源项现在与对应的整个方程行使用相同缩放：

```python
DMAT[4, i] += r_wgs / 1.2
DMAT[6, i] += (r_wgs - 3.0 * r_meth) * 1.02
```

保留WGS和甲烷化反应、原牛顿收敛阈值及输入煤质；没有通过关闭反应或归一化出口流量掩盖缺口。雅可比仍由实际方程数值微分获得。

同时统一晋华炉原子量、摩尔质量、气体常数、辐射常数、重力和标方换算，汽水侧改用IAPWS-IF97。权威来源、数值清单、兼容路径和未重新拟合的参数见 [物理常数说明](PHYSICAL_CONSTANTS.md)。

## 实际运行与回归

7组固定进料案例，均完成全炉计算并通过三组截面对比（进口→燃烧室、燃烧室→废锅、进口→废锅）：

| 案例 | 全流程最大单项差额 kg/h |
|---|---:|
| 典型工况/SciPy | 3.78×10⁻¹⁰ |
| 收紧FE/WE/X至1e-8、T至1e-5 | 3.78×10⁻¹⁰ |
| 改用legacy线性后端，仍采用新物性 | 8.73×10⁻¹¹ |
| RSC两项松弛系数均为零（诊断对照） | 5.02×10⁻¹⁰ |
| 二次氧OX_PART=0.9并添加CO₂比例0.05 | 5.53×10⁻¹⁰ |
| 煤内水2%，其余原元素/灰比例同比缩放 | 4.15×10⁻¹⁰ |
| 废锅单网格 | 7.49×10⁻¹⁰ |

另外完成9组正算/反算流程检查：正算、恢复基准、联合设计、高氧初值反算、低负荷反算、单废锅网格、二次氧、内层失败和废锅目标不可达。前7项成功，后2项按预期返回2并保留既有START。所有成功反算均满足原温差及气量容差。

联合设计目标为燃烧室1228℃/52000 Nm³/h、废锅780℃，实际解：

- 氧煤比 **0.9767153696**，水煤浆 **14.69179873 kg/s**。
- 燃烧室温差 **+0.00001221℃**，有效气量差 **+0.1686905 Nm³/h**。
- 废锅有效高度 **33.269545 m**，出口 **779.766527℃**，废锅吸热 **19.385335 MW**，产汽 **32.567652 t/h**。
- 此联合解另用完整状态独立核算三截面元素，最大单项差额 **2.48×10⁻¹⁰ kg/h**，通过；没有只检查目标值而忽略守恒。

原TEXACO `KMODEL=0` 仍62次收敛、出口 **1145.283048704397℃**；与此前性能优化前基线比较，T、FEMF、WE、X、QKW数组逐位相等，START文件字节相等。46项unittest全部通过，包含官方物性校核点和实际DMAT反应源项化学计量回归。

## 未通过与适用边界

挥发分XVM=0的额外边界诊断在默认其他输入、ITMAX=100时未收敛（最终温度修正量约1.122 K）。修正了该路径H/O/N/S传参和H₂S耗氢后，源项单元测试守恒；**仍不将这个全炉工况列为通过**。显式使用 `--cases zero-volatiles` 会报告失败，不输出成功验收。

本次没有证明整个操作范围可解、没有做独立全炉能量闭合，也没有标定传热/动力学/高压气体密度等经验近似；详见常数说明中的待验证项。
