# 燃烧室温度与有效气量反算

用户输入燃烧室出口温度（℃）和有效气量（CO+H₂，Nm³/h），求纯氧/无水无灰煤质量比 FOXY 与水煤浆总量 BSLURRY（kg/s）。煤浆浓度、煤质、氧气纯度、压力、进料温度及炉体参数保持用户设定。该模式也适用于 TEXACO 的第30格出口。

2026-11-02后续更新：RSC守恒修复及常数更新后已重新完成本模式验收，最新数值见[修复报告](ELEMENT_BALANCE_FIX.md)。下方初版结果保留为历史记录。

## 数值方法

外层采用两变量阻尼牛顿法，以 ln(FOXY)、ln(BSLURRY) 为变量，以温度和气量的允许误差归一化目标偏差。每轮对数变量扰动0.005，有限差分求2×2雅可比；温度已在容差内时优先向低氧侧差分，一个方向的内层未收敛时尝试另一方向。单轮对数步长限制为0.15、0.30，回溯系数为1、1/2、1/4、1/8、1/16，所有候选限制在用户边界内。仅接受目标偏差范数下降的候选。

每次候选都用 EINGAB 重建进料、氧气、煤水分配、几何及焓源项。第一次正常初始化；后续使用本次反算中最近的已收敛状态作初值，气/固流量按水煤浆负荷缩放，不读取外部历史重启文件。DMAT、反应热和原牛顿迭代方程保持不变。

成功必须满足内层收敛，且温差≤0.5℃、气量差≤max(1 Nm³/h, 目标气量×0.001)。最多40次试算；失败恢复最佳已收敛候选最多额外1次，以保证实际状态、输出条件与报告候选一致。内层失败、雅可比退化、边界受限或步长不能改善目标都明确报告失败，不把步长趋零作为成功。

默认氧煤比范围0.7–1.3、煤浆5–30 kg/s是搜索边界，不是设备安全操作范围，也不保证该范围内所有目标都有唯一解。局部搜索失败不等于数学上已证明无解。

## 与废锅目标温度联算

先在给定废锅初始高度下完成燃烧室反算，然后保持反算进料调用现有废锅高度搜索，重新求热负荷和产汽。最终再复核燃烧室温度和有效气量；只有全部启用目标成功才输出成功状态、覆盖 START。中间候选和失败设计不会覆盖已接受重启文件。

燃烧室反算记录保存在 `FEED_DESIGN_JSON`；废锅设计轨迹保存在 `RSC_DESIGN_JSON`。两个出口的温度、各气体 kmol/h 和灰 kg/h 写在同一 `OUTLET_FLOWS_JSON`，前端不根据修改后的输入推算旧结果。

## 输入和结果口径

- 可选第16行：`FEED_MODE,T_CHAMBER_C,EFFECTIVE_GAS_NMH`。缺失默认模式0；模式1启用反算。
- 可选第17行：`FOXY_MIN,FOXY_MAX,SLURRY_MIN,SLURRY_MAX`。初值须在正数搜索区间内。
- CO+H₂ 标方量 = (FEMF[3,30]+FEMF[6,30])×VM_NORMAL×3600。晋华炉按0℃/101325 Pa理想气体采用22.413969545014 Nm³/kmol；TEXACO对照模式仍为22.4。
- 组分 kmol/h = FEMF×3600；灰 kg/h = WE×(1−X)×3600。灰不含未反应碳，也不计入气体干湿基百分比。
- 输入显示采用 MPaG、℃；模型与历史文件保持绝压Pa、K。以101325Pa换算表压，API数值口径不变。
- 反算解单独显示，原进料输入保留搜索初值；使用反算值进行固定进料正算时，可把结果填入进料字段并切回模式0。
