# Web 工作台 UI 设计

范围：HTML + Flask。本文保留初次界面改版的设计与验收记录；后续Web已扩展到17行参数编辑，Streamlit仍编辑前11行并保留扩展。当前字段/单位以[输入协议](code_reference/05_INPUT_OUTPUT.md)为准。

## 设计规格

- 白色表面 #fff，冷灰画布 #f4f6f8，正文 #172c3e，次级文字 #647383，边线 #dce3e9。
- 主操作青绿 #147d73，温度曲线橙色 #e68136；无装饰渐变和 emoji。
- 顶栏 68 px，参数栏 320 px，内容边距 28 px，面板间距 18 px，圆角 8 px。
- Segoe UI / Microsoft YaHei / PingFang SC；标题 30 px，指标 29 px，面板标题 18 px，表单标签 12 px，正文 14 px。指标使用等宽数字。
- 左侧参数搜索、分组折叠、底部固定保存/运行；结果按总览、收敛过程、合成气、炉内分布切换，原始输出从顶栏进入。
- 总览：四指标带、温度主图、干基组成横条图、分段产汽和汽包压力。无结果时提供空态，不填示例数值。
- 760 px 以下参数区变为抽屉；1000 px 以下图表单列。表格内部滚动，保持页面无水平溢出。

## 数据与状态

- 初次打开读取已有结果；刷新时查询正在运行的任务并继续轮询。
- 图表在对应标签首次打开时绘制，切换时 resize，避免隐藏容器尺寸错误。
- 参数编辑标记旧结果；运行中冻结参数并保留上次结果；失败、未收敛、空数据单独提示。
- 热回收字段由 `web_backend/dataparser.py` 从同一 GASTEST 输出解析。没有热回收汇总时按 TEXACO 展示，缺值显示破折号。
- 搜索、折叠、标签页和抽屉支持键盘；按钮有 focus-visible，进度和消息提供可访问状态。

## 概念稿与实现差异

概念图用于布局、配色、字级和容器设计。图中示例参数标识改为项目真实变量名；干基图中的误绘 H₂O/Ar 改为真实 7 组分；温度轨迹和流量全部使用计算结果。概念图的近似数值不作为模型数据。

实现保留单一 HTML/CSS/JS 架构及本地 Plotly，不新增前端构建依赖。Streamlit 不在本轮改版范围。

## 第二轮细化：图表、双出口与目标温度

沿用上轮概念稿的白色/冷灰/青绿设计体系，本轮按用户要求扩展结果信息，无新增位图素材。

- 折线保持真实数据点之间的线性连接，不用平滑插值改写走势。增加更清晰的线宽/坐标字级、RSC 淡色区段、两个出口的标记及温度标注；多条收敛曲线同时区分颜色和线型。
- 表格改为固定表头、首列固定、交替底色、数字右对齐及出口行高亮，宽表只在自身容器滚动。
- 合成气按出口并列展示，保留相同的组分顺序和横轴范围，明确区分干基、湿基、组分流量和总流量；手机按出口上下排列。
- 侧栏新增废锅计算模式、目标温度、搜索高度和汽水条件；不适用的目标参数禁用，目标模式把高度输入标成“高度搜索初值”。
- 总览新增目标达成状态和高度/热负荷/产汽联动明细，失败输出明确为诊断信息。具体算法和复算数据见 `RSC_TARGET_DESIGN.md`。

对照检查保留了布局层级、配色、字体体系、容器圆角与间距；增加的出口卡片、参数组和设计结果是本轮用户明确要求的功能扩展。图表与表格已在 IAB 的 1536×1024、默认窗口和 390×844 窄屏检查，确认双出口信息齐全、图例可读及表格内部滚动。数值与显示使用同次计算结果。

## 第三轮：燃烧室反算、摩尔流量和工程输入单位

沿用既有设计体系，按用户要求新增燃烧室反算参数组、总览反算结果及轨迹。正算模式隐藏无关的反算目标/边界；切换反算时进料字段标为搜索初值。结果不自动覆盖输入初值，避免下次保存时无意改变工况。

合成气的两个出口均新增 kmol/h 列，并在气体表下单列灰 kg/h 和 CO+H₂ Nm³/h。气体表保持统一组分顺序、数字右对齐和干湿基分隔；灰不混入气体成分表。输入压力使用MPaG，输入温度使用℃；汽包结果压力同步以MPaG显示。

IAB 验证中使用真实隔离文件，输入6.6 MPaG和50℃，保存后读取文件分别为6,701,325 Pa和323.15 K。实际启动反算且ITMAX=1时，按钮/字段禁用，结束后显示失败及“结果仅供诊断”，不把未收敛工况显示为已完成。

| 对照项 | 概念及既有设计依据 | 本轮验证与处理 |
|---|---|---|
| 布局 | 固定顶栏、320px侧栏、四指标带及结果标签 | 结构保持，新增功能置于参数区和结果区 |
| 字体 | Segoe UI/微软雅黑、明确字级、数字右对齐 | 摩尔流量表沿用12px表格，结果单位单独一行避免长单位挤压 |

| 表格 | 固定表头/首列、交替底色、容器内滚动 | 五列完整显示；1450px以下出口卡片改为单列，390px手机视口表格307px、内容490px，在表内滚动 |
| 文案 | 工况结果、总览、合成气等现有导航 | 首屏仅增加用户要求的反算模式与提示、单位换算；未新增无关宣传文案 |

本轮将原1536×1024概念稿与实际页面截图在同一轮 `view_image` 检查，核对上述布局、字体、配色、容器、间距及文案差异。新增反算组/结果、摩尔流量列、灰流量与表压单位属于明确功能扩展；实际表格不以概念图中的示例数值填充。桌面与手机截图保存在会话交付目录中。

实际联算结果页已验证燃烧室双目标、废锅780℃目标、反算进料与高度/产汽汇总。修正了计算模式选项文字截断（选择框加宽至160px），以及默认1280px窗口两张五列表格过窄的问题。最终预览使用原工况的重新计算输出，并保留用户原标签内尚未保存的编辑。
