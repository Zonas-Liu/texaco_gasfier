# Web 工作台 UI 设计

范围：HTML + Flask，保留既有计算模型、前 11 行参数编辑和附加行保留规则。

## 设计规格

- 白色表面 #fff，冷灰画布 #f4f6f8，正文 #172c3e，次级文字 #647383，边线 #dce3e9。
- 主操作青绿 #147d73，温度曲线橙色 #e68136；无装饰渐变和 emoji。
- 顶栏 68 px，参数栏 320 px，内容边距 28 px，面板间距 18 px，圆角 8 px。
- Segoe UI / Microsoft YaHei / PingFang SC；标题 30 px，指标 29 px，面板标题 18 px，表单标签 12 px，正文 14 px。指标使用等宽数字。
- 左侧参数搜索、分组折叠、底部固定保存/运行；结果按总览、收敛过程、合成气、炉内分布切换，原始输出从顶栏进入。
- 总览：四指标带、温度主图、干基组成横条图、分段产汽和汽包压力。无结果时提供空态，不填示例数值。
- 760 px 以下参数区变为抽屉；1000 px 以下图表单列。表格内部滚动，保持页面无水平溢出。

## 数据与状态

- 初次打开读取已有结果；刷新时查询正在运行的任务并继续轮询。
- 图表在对应标签首次打开时绘制，切换时 resize，避免隐藏容器尺寸错误。
- 参数编辑标记旧结果；运行中冻结参数并保留上次结果；失败、未收敛、空数据单独提示。
- 热回收字段由 `web_backend/dataparser.py` 从同一 GASTEST 输出解析。没有热回收汇总时按 TEXACO 展示，缺值显示破折号。
- 搜索、折叠、标签页和抽屉支持键盘；按钮有 focus-visible，进度和消息提供可访问状态。

## 概念稿与实现差异

概念图用于布局、配色、字级和容器设计。图中示例参数标识改为项目真实变量名；干基图中的误绘 H₂O/Ar 改为真实 7 组分；温度轨迹和流量全部使用计算结果。概念图的近似数值不作为模型数据。

实现保留单一 HTML/CSS/JS 架构及本地 Plotly，不新增前端构建依赖。Streamlit 不在本轮改版范围。

## 浏览器验收

使用内置浏览器 IAB，在独立的输入/结果副本上进行交互测试。桌面 1536×1024、窄屏 390×844，以及浏览器默认视口分别检查。未改写用户的根目录结果和生产输入。

| 对照项 | 检查与修正 |
|---|---|
| 结构 | 顶栏、固定参数栏、四指标带、温度主图与组分图、底部回收带与概念稿一致 |
| 配色 | 保留纯白面板、冷灰画布、青绿操作和橙色温度线，没有增加渐变 |
| 字体 | 标题、指标、表单、按钮、图例与表格设置明确字级，数字对齐 |
